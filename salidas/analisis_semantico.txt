ERRORES SEMANTICOS
- Error de tipo: operacion entre tipos incompatibles int + float
- Error de tipo: no se puede asignar una expresion float a la variable y de tipo int
- Error de visibilidad: la variable z no esta declarada

SHADOWING
El metodo obtener_tipo_variable busca desde el ultimo ambito abierto hacia el ambito global.
En la linea y = y + x; encuentra primero la x del bloque interno.
Por eso la x usada es x_bloque_3 de tipo float y no x_global de tipo int.
